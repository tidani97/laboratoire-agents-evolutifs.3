

# CDI-01 — Organisation des expériences

## 1. Objectif

Ce document définit l'organisation des expériences réalisées dans le laboratoire CDI-01.

Nous cherchons à comprendre comment des agents autonomes, dotés de compétences différentes, peuvent apprendre, coopérer et s'adapter à différents environnements.

## 2. Conditions expérimentales

Trois configurations sont comparées.

### Condition A — Isolement

Chaque agent travaille individuellement, sans échange d'informations.

Objectif : mesurer les performances individuelles et les limites de l'absence de coopération.

### Condition B — Communication temporaire

Les agents échangent périodiquement leurs connaissances.

Objectif : mesurer l'effet des échanges d'informations sur les performances collectives.

### Condition C — Mémoire partagée

Les agents disposent d'une mémoire collective qui conserve les connaissances acquises.

Objectif : mesurer les bénéfices et les limites d'une connaissance accessible à toute l'équipe.

## 3. Environnements expérimentaux

Cinq environnements sont étudiés :

| Environnement | Caractéristique |

|---|---|

| Abondant | Ressources nombreuses |

| Rare | Ressources limitées |

| Dispersé | Ressources éloignées |

| Instable | Conditions changeantes |

| Mixte | Difficultés combinées |

## 4. Volume expérimental

La première campagne CDI-01 utilise :

- 20 graines aléatoires.

- 30 missions par condition.

- 30 tours par mission.

- 3 conditions expérimentales.

Total : 1 800 missions.

Cette organisation permet de comparer les résultats dans plusieurs conditions aléatoires.

## 5. Indicateurs d'évaluation

Les mesures principales sont :

- Score collectif.

- Réussite des actions.

- Connaissances accumulées.

- Contribution de chaque agent.

- Influence de l'environnement.

- Effet des différentes formes de communication.

## 6. Analyse des résultats

Les résultats doivent être regroupés par condition et par environnement.

Nous devons notamment rechercher :

- Les différences de performances.

- Les situations favorisant la coopération.

- Les situations favorisant l'autonomie.

- Les éventuels déséquilibres entre agents.

- Les limites de la mémoire collective.

Les moyennes ne suffisent pas : la dispersion des résultats et leur variabilité devront aussi être étudiées dans les prochaines versions.

## 7. Précautions scientifiques

Les résultats de CDI-01 sont exploratoires.

Ils dépendent des règles et paramètres définis dans le programme.

Une différence de score ne prouve pas à elle seule qu'un mécanisme est universellement supérieur.

Les expériences futures devront contrôler les variables, multiplier les scénarios et vérifier la reproductibilité des résultats.

## 8. Perspectives

Les prochaines campagnes devront introduire progressivement :

- La mémoire individuelle.

- L'apprentissage par renforcement.

- Les mutations des compétences.

- La sélection des stratégies.

- La transmission entre générations.

- L'apparition de nouvelles spécialisations.

## 9. Question de recherche

Dans quelles conditions un groupe d'agents spécialisés peut-il développer des capacités collectives supérieures à celles de ses membres pris individuellement ?
