

# CDI-01 — Architecture des agents autonomes

## 1. Philosophie générale

Le laboratoire CDI-01 repose sur trois agents autonomes possédant des compétences initiales différentes.

Aucun agent ne possède toutes les capacités nécessaires pour réussir seul dans toutes les situations.

Leur complémentarité doit favoriser :

- La coopération.

- La spécialisation.

- L'apprentissage.

- L'adaptation.

- Le partage des connaissances.

L'objectif est d'observer si un collectif d'individus différents peut développer des stratégies plus performantes qu'un individu isolé.

## 2. Agent Explorateur

### Compétence principale : observation

Capacités initiales :

| Compétence | Niveau |

|---|---:|

| Observation | 90 |

| Analyse | 25 |

| Construction | 20 |

Rôle :

- Explorer l'environnement.

- Repérer les ressources.

- Détecter les changements.

- Transmettre les informations utiles.

Limites :

- Analyse limitée.

- Capacité de construction réduite.

- Dépendance aux autres agents pour exploiter certaines découvertes.

## 3. Agent Analyste

### Compétence principale : analyse

Capacités initiales :

| Compétence | Niveau |

|---|---:|

| Observation | 25 |

| Analyse | 90 |

| Construction | 25 |

Rôle :

- Interpréter les informations.

- Identifier les opportunités.

- Comparer les stratégies.

- Anticiper les difficultés.

Limites :

- Observation limitée.

- Capacité de construction réduite.

- Dépendance aux informations disponibles.

## 4. Agent Constructeur

### Compétence principale : construction

Capacités initiales :

| Compétence | Niveau |

|---|---:|

| Observation | 20 |

| Analyse | 25 |

| Construction | 90 |

Rôle :

- Transformer les ressources en réalisations.

- Mettre en œuvre les stratégies.

- Participer à la production collective.

- Exploiter les ressources découvertes.

Limites :

- Observation limitée.

- Analyse limitée.

- Dépendance aux informations et aux stratégies des autres agents.

## 5. Principes d'interaction

Les agents peuvent fonctionner selon trois configurations :

### A. Isolement

Chaque agent agit sans communication avec les autres.

### B. Communication temporaire

Les agents échangent périodiquement des informations.

### C. Mémoire partagée

Les connaissances collectives sont conservées et accessibles aux agents.

## 6. Évolution future

Les prochaines versions devront introduire :

- Une mémoire individuelle.

- Une évolution progressive des compétences.

- Des mutations aléatoires.

- Une sélection basée sur les résultats.

- Une transmission des caractéristiques aux générations suivantes.

- La possibilité de développer de nouvelles spécialisations.

## 7. Règle fondamentale

Aucune spécialisation ne doit être considérée comme supérieure dans tous les environnements.

Un agent performant dans un environnement peut devenir moins efficace dans un autre.

La valeur d'un agent doit être étudiée à travers ses capacités individuelles et sa contribution au collectif.

## 8. Question centrale du laboratoire

La coopération entre agents aux capacités différentes peut-elle faire émerger une intelligence collective capable de s'adapter à des environnements changeants ?
